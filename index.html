Política de Privacidade

Aplicativo de registro de medicação

1. Sobre o Aplicativo

Este aplicativo é uma ferramenta pessoal para registro de horários de medicação. No momento, não possui fins comerciais e não há venda de serviços ou produtos.

2. Coleta, armazenamento e compartilhamento de dados
  • Este aplicativo não coleta dados pessoais nem compartilha dados com terceiros.
  • Todos os dados são armazenados localmente no dispositivo do usuário.
  • Nenhuma informação é transmitida para servidores externos.
3. Permissões e Segurança
  • O aplicativo não requer permissões sensíveis além das necessárias para seu funcionamento básico.
  • A segurança das informações depende do próprio dispositivo do usuário.
4. Uso e Boas Práticas
  • O uso do aplicativo é de responsabilidade exclusiva do usuário.
  • Manter seu dispositivo seguro.
  • Proteger o acesso ao seu dispositivo contra uso não autorizado.
  • Realizar backup dos dados, se considerar necessário.
  • Utilizar o aplicativo de forma consciente e adequada.
5. Isenção de Responsabilidade
  • O aplicativo não garante a precisão das informações inseridas.
  • O aplicativo não substitui orientação médica.
  • O desenvolvedor não se responsabiliza por quaisquer danos decorrentes do uso do aplicativo.
